    WIFIGATE Host

    So funktioniert's

    Von der Buchung zum offenen Tor, automatisch

    Drei Schritte, danach läuft es bei jeder Reservierung von selbst.

    1. Eine Buchung geht ein

      Verbinden Sie Ihr Buchungssystem über das Dashboard auf der WIFIGATE-Website. Ihr Buchungssystem meldet WIFIGATE Host jede bestätigte Buchung. Sie können eine Buchung auch von Hand im Dashboard eingeben.

    2. Der Zutritt wird automatisch erstellt

      WIFIGATE Host erstellt einen sicheren Zugangslink für genau das Tor, die Tür oder den Parkplatz dieser Buchung, gültig nur für den Aufenthalt. Sie oder Ihr Buchungssystem senden ihn an den Gast.

    3. Ihr Gast kommt direkt hinein

      Der Link öffnet die WIFIGATE-App automatisch mit der passenden Zutrittsberechtigung, und der Gast öffnet den Eingang mit seinem Smartphone. Beim Check-out endet der Zutritt von selbst. Kein Schlüssel, der eingesammelt werden muss.

    Häufige Fragen

    Wie erhält der Gast Zutritt?

    WIFIGATE Host erstellt für jede Buchung einen privaten Zugangslink. Sie oder Ihr Buchungssystem senden ihn per SMS, E-Mail oder WhatsApp an den Gast, und Sie können ihn auch als QR-Code anzeigen.

    Muss der Gast eine App installieren?

    Ja, die WIFIGATE-App. Der Link öffnet sie automatisch mit der passenden Zutrittsberechtigung für die Buchung, und der Gast meldet sich mit Google oder Apple an. Ohne die App führt der Link zur Installationsseite; nach der Installation öffnet der Gast den Link erneut.

    Wann beginnt und wann endet der Zutritt?

    Er richtet sich nach Check-in und Check-out der Buchung. Standard ist die Anreise um 15:00 und die Abreise um 12:00, und Sie können andere Uhrzeiten festlegen.

    Mit welchen Buchungssystemen lässt es sich verbinden?

    Mit jedem System, das Buchungen über eine API oder einen webhook senden kann: einem Property-Management-System (PMS), einem Channel-Manager oder Ihrem eigenen System. Sie können Buchungen auch von Hand im Dashboard eingeben.

    Funktioniert es für eine Anlage mit mehreren Eingängen?

    Ja. Eine Buchung kann eine Gruppe von Eingängen öffnen, zum Beispiel ein Tor, einen Parkplatz und eine Tür, mit bis zu 20 Systemen pro Gruppe.

    Was muss installiert werden?

    Ein WIFIGATE-Controller an jedem Eingang. Der Admin des Tors fügt ihn aus der App zu WIFIGATE Host hinzu, direkt am Tor. Am Eingang wird kein Wi‑Fi benötigt.

    Benötigt das WIFIGATE-System eine Internetverbindung?

    Nein. Für WIFIGATE Host benötigt das WIFIGATE-System weder eine Internet- noch eine Wi‑Fi-Verbindung. Der Eingang wird über Bluetooth zwischen dem Smartphone des Gastes und dem Controller geöffnet, ohne Abhängigkeit von der Cloud im Moment des Eintritts. Das Smartphone des Gastes braucht Internet nur, um den Link zu empfangen und sich in der App anzumelden.

    Wie wird der Preis berechnet, und gibt es einen Mindestbetrag?

    Nach der Anzahl der aktiven Systeme, Stufe für Stufe: $6 pro System für bis zu 14 Systeme, $5 für die Systeme 15–49 und $4 ab dem 50. System. Der Mindestbetrag pro Konto beträgt $6 pro Monat, auch ohne verknüpftes System. Ein System, das nur einen Teil des Monats aktiv war, wird tageweise berechnet.

    Alles beginnt mit einem WIFIGATE-Controller

    Der Gastzugang läuft über einen WIFIGATE-Controller, der am Tor, an der Tür oder an der Parkplatzzufahrt installiert ist. Wählen Sie im Shop den passenden Controller für Ihre Eingänge.
