    WIFIGATE Manager

    모든 시스템을, 전 세계 어디서나

    WIFIGATE Manager는 조직의 모든 게이트, 출입문, 주차 차단기, 셔터를 하나의 웹 대시보드로 모아 줍니다. 모든 현장의 사용자, 권한, 기록을 어떤 브라우저에서든 관리하세요.

    요금

    WIFIGATE Manager, 간단한 요금

    관리하는 시스템에만 비용을 지불하세요. WIFIGATE 컨트롤러 자체는 구독이 전혀 필요 없습니다.

    하나의 간단한 요금

    시스템

    $1.90/ 시스템 / 월

    Gate, Dual Control 또는 셔터

    대시보드의 모든 활성 시스템, 위치와 관계없이.

    • 여러 그룹에 있어도 시스템은 한 번만 계산
    • 그룹은 무료: 그룹 안의 시스템만 계산
    • 활성 시스템이 없으면 시스템 요금도 없음
    • 월 중간에 추가한 시스템은 일할 계산
    문의하기

    조직

    $1/ 추가 조직 / 월

    처음 3개 조직 포함

    서로 다른 건물, 고객, 회사를 하나의 계정으로 운영하세요.

    • 모든 계정에 3개 조직 포함
    • 추가 조직당 월 $1
    • 조직 관리자는 무료
    • 하나의 계정, 월 1회 청구서
    문의하기

    예시

    $21/ 월

    10개 시스템 · 5개 조직

    10개 시스템 × $1.90, 여기에 추가 조직 2개 × $1.

    • 게이트 1개: $1.90 / 월
    • 게이트 2개와 Dual Control 1개로 구성된 그룹: $5.70
    • 셔터 1개: $1.90 / 월
    • 세전 월 예상 금액
    문의하기

    요금은 미국 달러(USD) 기준이며 세금 별도입니다. 매월 초 한 번의 청구로 지난달 이용분을 일할 계산하며, WIFIGATE Host를 이용하는 경우 함께 청구됩니다.

    시스템 연결

    앱에서 WIFIGATE 시스템을 대시보드로 내보내세요. 컨트롤러는 Wi‑Fi로 연결됩니다.

    원하는 방식으로 정리

    게이트, 출입문, 셔터를 건물, 현장 또는 조직별로 그룹화하세요.

    어디서나 관리

    출입 권한을 부여하고 회수하며, 기록을 확인하고, 모든 시스템을 어떤 브라우저에서든 제어하세요.

    모든 출입구. 하나의 대시보드.

    • 01 / 06

      모든 현장을 한눈에

      모든 건물, 게이트, 출입문을 위치와 관계없이 하나의 대시보드에서 확인하세요.

    • 02 / 06

      사용자와 권한

      사용자를 추가하고, 누가 무엇을 열 수 있는지 정하고, 시스템 하나든 현장 전체든 몇 초 만에 변경하세요.

    • 03 / 06

      전체 출입 기록

      모든 현장에서 누가 언제 어느 출입구를 열었는지 확인하세요.

    • 04 / 06

      조직과 그룹

      시스템을 건물이나 고객별로 그룹화하고, 조직마다 전용 관리자를 지정하세요.

    • 05 / 06

      전 세계 어디서나

      컴퓨터, 태블릿, 스마트폰의 어떤 브라우저에서든 관리하세요.

    • 06 / 06

      기존 설비 그대로

      게이트, Dual Control 게이트, 출입문, 셔터 모두 같은 대시보드에 연결됩니다.

    대상:주거용 건물사무실스포츠 시설주차장
    보안

    대규모 제어도 안전하게

    많은 출입구를 관리하는 조직을 위해 설계되었습니다.

    종단 간 암호화

    명령과 권한이 암호화되어 전송 중에 출입 정보를 읽거나 복사할 수 없습니다.

    현장에서의 열기는 그대로

    출입구에서 스마트폰으로 여는 기능은 인터넷 연결이 없어도 로컬에서 계속 작동합니다.

    팀별 역할

    각 조직의 관리자는 자신이 담당하는 시스템만 관리합니다.

    모든 현장을 한곳에서 관리할 준비가 되셨나요?

    보유하신 건물과 시스템에 대해 알려 주세요. 고객님의 조직에 맞게 WIFIGATE Manager를 설정해 드립니다.
